Part C: Create Your Own Program (Favorite Foods)

public class FavoriteFoods {
    public static void main(String[] args) {
        String[] foods = {"Pizza", "Burger", "Spaghetti", "Chicken", "Ice Cream"};

        for (String food : foods) {
            System.out.println(food);
        }
    }
}

Part VI: Learning Check

A for each loop is useful because it provides a simpler, cleaner syntax to access every element in an array without having to manage an index counter manually. This reduces coding errors and makes the program much easier to read when you simply need to process every item.
